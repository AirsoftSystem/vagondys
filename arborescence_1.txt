### Contexte
Projet **VAGONDYS** : système Next.js de contrôle airsoft avec cibles ESP32. Migration complète de l’application Flutter (`scores_screen.dart`) vers une interface STAFF web intégrée au portail existant.

### Infrastructure technique
- **9 couloirs** : 1 à 8 (standard) + 9 (Ultimate Corridor avec 4DX)
- **Architecture** : VSC → GitHub → Vercel + Cloudflare + Render ↔ Supabase (MASTER + PUBLIC + STAFF par ville)
- **Communication** :
  - WebSocket entre Next.js et ESP32 pour scores + commandes
  - HTTP pour l’affichage TV (scores, décompte, overlay)

### Rôle des écrans
- **PC STAFF** : interface de contrôle (sélection couloirs + modes, validation, commandes globales)
- **ÉCRAN TV** : affichage des scores (case clignotante = joueur actif), décompte vocal, overlay FIN GAME. Pas d’internet, uniquement réseau local.

### Bouton physique (sous chaque écran TV)
- LED intégrée : **allumée** = action possible, **éteinte** = action impossible
