### 6. PROBLÈMES RÉSOLUS

| Problème | Solution |
|----------|----------|
| Multiples comptes GitHub/Supabase | Unification en 1 compte GitHub + 1 projet Supabase |
| Variables d'environnement par ville | Variables UNIFIÉES (plus de MASTER, NANTES, etc.) |
| Fichiers JSON trop volumineux | Compression GZIP (gain 60-70%) |
| Doublons messages (client + staff) | `messages_history` = CLIENT uniquement, `communication_replies` = STAFF uniquement |
| Pas d'archive GitHub après confirmation | Archivage dans `confirm-signal/route.ts` |
| Pas de mise à jour archive après réponse staff | Archivage dans `send-reply/route.ts` |
| Redirections en boucle staff | Correction `proxy.ts` avec `createServerClient` |
| Ville d'archivage incorrecte | Utilisation `payload.city` (pas `city_code`) pour le chemin |
| Fichiers .gz non listés/lus | Support `.json.gz` dans `listAllArchiveFiles`, `findFileInRepo`, `restore` |
| Messages centralisés non filtrés | Admins sans filtre ville |
| Géolocalisation | IP → ville la plus proche (formule Haversine) |
